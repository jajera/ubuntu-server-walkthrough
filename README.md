# ubuntu-server-walkthrough

Ubuntu Server from ISO to SSH-ready host.

Docs: [ubuntu-server-walkthrough.johna.kiwi](https://ubuntu-server-walkthrough.johna.kiwi/)

## Docs locally

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/zensical serve
```

Open the URL printed by the server (usually `http://127.0.0.1:8000`).
